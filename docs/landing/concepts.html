Capture-the-Wool authoring and analysis

Map layouts begin asa grid of typed rectangles.

A plan assigns a role to every rectangle — spawn, wool room, connector, buffer — and defines the lanes, the mid and the build zones. Compiling it produces the island geometry, the terrain paint, the objective placements and an exportable map.xml. All map data is held in the database rather than in loose files.
